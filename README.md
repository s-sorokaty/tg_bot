# QUIZ_bot 
Бот позволяет запускать квиз тест в виде телеграмм бота

# Перед запуском

Перед запуском необходимо настроить окружение 

- Файл окружения bot/.env
- Пример файла оружения example.env

Переменные:

BOT_TOKEN='TOKEN' - токен телеграмма для работы бот

ACCESS_USER_IDS=[1,2] -  неиспользуемая переменная

CHAT_TO_SEND_RESULT=[1234] - id чата в который необходимо отправлять уведомление о пройденном тесте. Предварительно бота необходимо добавить в этот чат

## Запуск через docker compose
### Порядок команд для запуска

1. docker-compose build # сборка контейнеров
2. docker-compose up -d # включение собранного контейнера
3. docker-compose down # отключить контейнер

## Запуск нативно

### Порядок команд для запуска

Необходимые утилиты:
- poetry
- python 3.11

1. cd bot && poetry install # установка необходимых библиотек
2. python main.py # запуск приложения
